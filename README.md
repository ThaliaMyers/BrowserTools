# BrowserTools
![Static Badge](https://img.shields.io/badge/Platforms-iOS%2017%2B%20%7C%20macOS%2014%2B%20%7C%20visionOS-h)

BrowserTools provides a few basic browser/web related functions such as simplified url formatting and favicon loading from a url.

## Installation
To install with [Swift Package Manager](https://swift.org/package-manager/), add the following as a dependency to your `Package.swift`:

```swift
dependencies: [
    .package(url: "https://github.com/ThaliaMyers/BrowserTools.git", from: "1.0.0")
]
```
